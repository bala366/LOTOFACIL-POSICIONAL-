# Lotofácil Posicional

Aplicativo Android para estudar tendências da Lotofácil usando:

- Engrossando o talo das repetidas
- Talo do espelho
- Posicionamento P01 a P15 inspirado no estudo do vídeo
- Ciclo atual aberto e ciclos completos anteriores
- Perímetro, miolo, cruz, linhas, colunas, soma, primos e Fibonacci

## Como gerar APK no GitHub

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta.
3. Abra a aba **Actions**.
4. Execute o workflow **Compilar APK Lotofacil Posicional**.
5. Baixe o artefato **LOTOFACIL-POSICIONAL-APK**.

## Fluxo do app

1. Importar arquivo TXT de resultados.
2. Escolher 8, 9 ou 10 repetidas.
3. Tocar em **Analisar Próxima Tendência**.
4. Ver progresso e ranking final.

> Estudo estatístico de tendência. Não garante resultado de sorteio.
